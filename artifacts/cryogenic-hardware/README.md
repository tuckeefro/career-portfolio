# Maybell: instrumentation and operator controls

![Measurement and operator-command paths](instrumentation-flow.svg)

This figure separates the measurement/display work from the operator-command path described in [the project account](../../projects/cryogenic-hardware.md). Tucker set up and wired the Lake Shore Model 372, integrated its readout through a LattePanda, and brought system measurements and pneumatic-valve controls into a unified GUI.

The two GUI boxes represent the same interface in two functional paths. Acquisition wiring, transport protocols, control electronics, timing, and measurement accuracy remain unspecified. The drawing is reconstructed from the account; an original schematic or GUI screenshot is not included.

The [public APS presentation record](https://meetings-archive.aps.org/mar/2023/q72/5/) linked by the project page documents the team cable presentation. It does not independently verify this instrumentation arrangement.
