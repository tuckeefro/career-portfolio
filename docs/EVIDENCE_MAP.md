## Review in small passes

Review one figure at a time. Useful feedback is a brief correction such as “that happened in a different order,” “I did this part,” or “that photo shows the filter, not the receiver.”

Original evidence can be supplied as a folder location or a messy collection of files. Sorting, naming, captions, page structure, and figure production belong to the assistant. Unknown values remain unknown until a source or clearly labeled recollection is supplied.
