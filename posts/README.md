# Posts with inspectable work

Start with the [waterjet repair](waterjet-repair.md) for mechanical, equipment, and manufacturing audiences. It has a concrete cutting fault, an inspection finding, a repair you carried out, and a reported return to production after three working days.

The [transit analysis](transit-service.md) shows a different skill: preserving a useful measurement when route names and reporting periods change. Its public table, calculations, sources, and checking script let a reader examine the result.

Each packet includes copy, a PNG to attach, a caption, alt text, and links to the supporting record. These are prepared drafts; no social post has been published.

## Posting sequence

1. Attach the PNG from the packet.
2. Copy the post text and include its case link.
3. Use the supplied alt text.
4. Keep the figure's reconstruction or scheduled-service label visible.

A repair photo or service record would strengthen the waterjet case if you have one. The current version can be presented as your own repair account with a clearly labeled reconstruction.
